# Challenge Listing – React

Cette application permet d’afficher une liste de challenges et d’accéder au détail de chacun d’eux.  

---

## Fonctionnalités

- **Page d'accueil** : Afficher une liste de challenges avec un header
- **Page de détail du challenge** : Afficher les détails complets lors du clic sur un challenge
- **Routing** : Navigation entre la liste et les vues de détail

---

## Stack technique

- NextJS
- React
- Typescript
- Tailwind CSS

---

## Installation

1. Cloner le repository :
```bash
git clone https://github.com/manon-coulombe/ma-voie.git
```
2. Installer les dépendances puis lancer le projet en local :
```bash
npm install
npm run dev
```
L’application est accessible à l’adresse :
http://localhost:3000
